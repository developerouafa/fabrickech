🧵 Fabrickech
Multilingual E-Commerce Platform

📌 About the Project | حول المشروع

EN
Fabrickech is a full-stack e-commerce platform designed to demonstrate real-world business logic using Laravel and Inertia.js.
It includes a powerful admin dashboard, a modern SPA frontend, multilingual support, and a REST API ready for mobile or third-party integrations.

Fabrickech هو مشروع تجارة إلكترونية متكامل يهدف إلى إبراز تطبيق عملي لمنطق الأعمال الحقيقي باستخدام Laravel و Inertia.js.
يتوفر على لوحة تحكم قوية، واجهة أمامية حديثة (SPA)، دعم تعدد اللغات، وواجهة API قابلة للربط مع تطبيقات خارجية.
